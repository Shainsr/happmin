# Happ VPN – تغییرات نسخهٔ توسعه

## قابلیت‌های اضافه‌شده

- **پینگ واقعی Xray:** اندازه‌گیری تأخیر سرور از مسیر تست HTTP هستهٔ Xray.
- **TCP Ping:** اندازه‌گیری زمان برقراری اتصال TCP به آدرس و پورت endpoint سرور.
- **تست گروهی:** تست سرورها با حداکثر ۵۰ کار هم‌زمان و نمایش نوار پیشرفت.
- **مرتب‌سازی:** مرتب‌سازی از کمترین تأخیر بر اساس نوع پینگ انتخاب‌شده؛ موارد تست‌نشده و ناموفق در انتهای فهرست قرار می‌گیرند.
- **ذخیره نتایج:** نتیجهٔ پینگ واقعی و TCP جداگانه ذخیره می‌شود.
- **فونت فارسی:** تم برنامه از Vazirmatn استفاده می‌کند. فونت در اولین اجرای دارای اینترنت دریافت و توسط `google_fonts` cache می‌شود.
- **کاشی Quick Settings:** گزینهٔ Happ VPN برای پنل تنظیمات سریع اندروید.
- **ویجت صفحهٔ اصلی:** ویجت وضعیت و دکمهٔ اتصال/قطع اتصال.

## ساخت پروژه

از پوشهٔ ریشهٔ پروژه:

```bash
flutter pub get
flutter analyze
flutter build apk --release
```

## افزودن کاشی و ویجت در اندروید

1. برنامه را نصب و حداقل یک‌بار باز کن.
2. پنل Quick Settings را باز کن، وارد حالت ویرایش شو و کاشی **Happ VPN** را به پنل اضافه کن.
3. روی صفحهٔ اصلی لانچر لمس طولانی انجام بده، بخش Widgets را باز کن و ویجت **Happ VPN** را اضافه کن.

برای اجرای فرمان، کاشی یا ویجت برنامه را باز می‌کند؛ کنترل اتصال همچنان از همان هستهٔ `flutter_v2ray` انجام می‌شود.

## نکات اندازه‌گیری

- **پینگ واقعی**، زمان پاسخ‌گویی درخواست آزمایشی از مسیر هستهٔ Xray است؛ پینگ ICMP خام نیست.
- **TCP Ping** زمان اتصال TCP به endpoint استخراج‌شده از کانفیگ را گزارش می‌کند. این مقدار با تأخیر کامل تونل یا handshake لایهٔ TLS یکی نیست.
- برای تست گروهی، ۵۰ سرور به‌صورت موازی پردازش می‌شوند. اجرای تعداد زیادی تست واقعی Xray ممکن است روی گوشی‌های ضعیف فشار CPU و حافظه ایجاد کند.
- ویجت و کاشی Quick Settings فعلاً با باز کردن Activity، فرمان را به هستهٔ Flutter می‌فرستند؛ اجرای مستقل سرویس VPN از داخل Tile در این نسخه پیاده‌سازی نشده است.

## وابستگی‌ها

نسخه‌های pubspec به نسخه‌های منتشرشدهٔ فعلی وابستگی‌ها تنظیم شده‌اند. `shared_preferences` نیز از بخش اشتباه `flutter:` به بخش اصلی `dependencies:` منتقل شده است.
